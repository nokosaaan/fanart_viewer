Fanart Viewer — 補助スクリプトの使い方
========================================

このフォルダ(exe\)には、ビルド済みのアプリ(fanart_viewer.exe)を操作するための
補助スクリプトがいくつか同梱されています。中でも「キャラクター分類器の学習」
(train.ps1)は少し分かりにくいので、このファイルでまとめて説明します。

【追記】普段アプリをそのまま(ダブルクリックで)使っている場合は、PowerShellの
train.ps1を使わなくても、アプリ本体のヘッダーメニュー「バックアップ」の下に
ある「分類器の学習」からGUIで同じことができます。パラメータ(除外キャラ名・
最低画像枚数など)も画面上のフォームで設定でき、進捗ログもその場に表示されます。
以下のtrain.ps1の説明は、PowerShellから直接使いたい場合(細かいオプションを
全部使いたい場合など)の説明です。


----------------------------------------
train.ps1 — キャラクター分類器を学習する(PowerShellから使う場合)
----------------------------------------

【これは何のためのスクリプト？】

編集キューの「提案を開始」ボタンは、内部で「キャラクター分類器」という
このアプリ専用のAIモデルを使って、画像に写っているキャラクターを自動で
提案しています。このモデルはビルド直後は空っぽ(まだ何も学習していない状態)
です。自分のDBに実際に登録した画像・キャラクター名を使って train.ps1 で
学習させないと、キャラクターの自動提案はほとんど機能しません。

つまり、基本的な流れはこうなります:

  1. アプリを使って画像を取得し、編集キューでタイトル・キャラクター名を
     手作業でどんどん登録していく(最初のうちはこの手作業が必要です)
  2. 各キャラクターの画像がある程度(目安: 1キャラあたり15枚以上)溜まったら
     train.ps1 を実行する
  3. 以降、編集キューの「提案を開始」でそのキャラクターが自動候補に出る
     ようになる
  4. 新しいキャラクター・画像が増えるたびに、また train.ps1 を実行して
     学習し直す(何度でも再実行できます。前回のモデルは上書きされます)


【使い方(基本)】

1. 先に .\build.ps1 でアプリをビルドしておいてください
   (dist\fanart_viewer\fanart_viewer.exe が存在している必要があります)。

2. PowerShellをこの exe フォルダで開き、以下を実行するだけです:

     .\train.ps1

   これだけで、推奨設定(下記【デフォルト値について】参照)で学習が
   始まります。

3. 進捗は画面にリアルタイムで表示されます
   (裏では %USERPROFILE%\.fanart_viewer\training.log というログファイルに
   書き込まれ、それを1秒おきに読み直して画面に出しています。アプリ本体は
   ウィンドウの無いバックグラウンド処理として動くため、この方式になって
   います)。

4. 学習には数分〜数時間かかることがあります(登録済みの画像の枚数次第です)。
   終わると最後に

     Training process exited with code 0.

   のように表示されます(0 が正常終了、0 以外はエラーです。エラーの場合は
   その直前に表示されているログの内容を確認してください)。

5. 【重要】学習が終わったら、fanart_viewer.exe を一度完全に終了して、
   起動し直してください。アプリは起動時に読み込んだモデルをメモリ上に
   保持し続けるため、再起動しない限り新しく学習した結果は反映されません。


【デフォルト値について】

何もオプションを付けずに .\train.ps1 とだけ実行すれば、そのまま実用上の
推奨設定(標準バックエンド・1キャラあたり最低15枚・線形モデル)で動きます。
わざわざオプションを指定する必要があるのは、基本的に次の1つだけです:

  --exclude キャラ名1,キャラ名2
      特定の名前を学習対象から除外します。例えば「複数人が写っている画像
      全員まとめて」につけた便宜上の名前(グループ名的なラベル)がキャラ
      クター名として登録されてしまっている場合、それをそのまま学習させると
      分類器の精度が落ちるので、この名前を --exclude で除外してください。

      例:

        .\train.ps1 --exclude 集合カットまとめ

      複数指定する場合はカンマ区切りです:

        .\train.ps1 --exclude 集合カットまとめ,その他の除外名


【その他、興味があれば使えるオプション(通常は不要)】

  --min-images N
      1キャラあたり最低これだけの枚数が無いと学習対象にしません
      (デフォルト15。無理に下げると信頼度の低いモデルになりがちです)。

  --include-multi-character
      通常は1人だけ写っている画像だけを学習に使いますが、これを付けると
      複数人が写っている画像(「領域ラベル付けキュー」で手動ラベル済みの
      ものなど)も学習に混ぜます。件数が少ないうちは付けなくても問題
      ありません。

  --backend canary
      標準(onnx)より高精度だが遅い、別のAIモデルに切り替えます。処理速度
      がかなり遅くなるので、通常は指定不要です。

  上記以外にも細かいオプションがあります。全一覧は以下で確認できます:

     .\train.ps1 --help


【うまくいかない場合(「認識されません」と出る場合)】

「.\train.ps1 は、コマンドレット、関数、スクリプト ファイル、または操作可能な
プログラムの名前として認識されません」というエラーが出る場合、ファイル自体は
存在していても、Windowsのスクリプト実行制限(実行ポリシー)によってブロック
されている可能性があります。以下を試してください:

     Get-ExecutionPolicy -List
     Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
     Unblock-File -Path .\train.ps1

(1つ目で現在の設定を確認、2つ目で今のユーザーだけこのPC上のスクリプトを
実行できるようにし、3つ目はZIPでダウンロードした場合などに付く「ブロック」
マークを外します)。それでも変わらない場合は、上記のGUI(アプリ本体の
「分類器の学習」メニュー)を使ってください — PowerShellを一切経由しません。

その他のスクリプト(参考)
----------------------------------------

  build.ps1     アプリ本体をビルドします。train.ps1 / reset_db.ps1 を
                使う前に、最初に一度実行しておく必要があります。

  reset_db.ps1  ローカルのデータベースを初期化(消去)します。通常の運用
                では使いません — 使い方はスクリプト内のコメントを参照して
                ください。

  train.sh / reset_db.sh / build.sh
                上記それぞれの Windows(.ps1)版に対応する、Linux/Mac向けの
                シェルスクリプト版です。中身は同じことをします。
